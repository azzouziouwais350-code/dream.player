# dream.player

Lecteur de musique « pixel dreamcore » en PWA : import de mp3 (glisser-déposer, playlist, visualiseur) et lecteur Spotify intégré.

## Utilisation
Ouvre `index.html` ou publie le dossier sur GitHub Pages (Settings → Pages → Branch main / root), puis installe l'appli depuis ton navigateur.
